# Inverted-Search
Developed an Inverted Search project in C using hash tables and linked lists to efficiently index words from multiple files. The project supports database creation, searching, displaying word occurrences, updating the database, and saving indexed data, demonstrating strong knowledge of data structures, file handling

## Features

- Create an inverted index from multiple text files
- Search for a specific word
- Display the complete database
- Update the database with new files
- Save the indexed database
- Efficient word searching using hashing
- Handles word occurrences across multiple files

## Technologies Used

- C Programming
- Data Structures
- Hash Tables
- Linked Lists
- File Handling
- Linux
## Operations

1. **Create Database**  
   Reads the input files and creates the inverted index.

2. **Search Database**  
   Searches for a word and displays the files containing that word along with occurrence counts.

3. **Display Database**  
   Displays the complete inverted search database.

4. **Update Database**  
   Adds information from new files to the existing database.

5. **Save Database**  
   Saves the indexed database for future use.
